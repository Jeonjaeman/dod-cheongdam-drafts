## 공통 사실 및 의료 표현 기준
홈페이지에서 서비스 존재를 확인한 것과 치료 효능을 입증한 것은 다르다. '국내 최초', '안전성/효과 검증', '세포의 시간을 되돌리는', '회복 보장' 문구는 새 초안에서 사용하지 않는다. 재생 프로그램은 기관 지정과 개별 치료 승인/효능을 구분하고 의료진 검토 전 상세 효능 카피는 보류한다. 생성 이미지는 추상적 브랜드 연출만 허용하고 실제 병원·의사·환자·장비·치료 결과 사진인 것처럼 사용하지 않는다. 실제 직원 인물과 시설 사진은 고객 제공/이용권한 확인 자산 사용.

## A — PRIVATE ATELIER / 나에게 집중하는 진료
- 컨셉: 프라이빗 공간과 상담 경험을 중심으로 한 고요한 시네마틱 브랜드 사이트.
- 타깃 가설: 장비명보다 신뢰·공간·개별 상담 경험을 중시하는 첫 방문자. 고객 확인 전 가설임.
- 메시지: '나의 피부에 집중하는 시간' / 보조: '피부 상태를 살피고, 나에게 맞는 진료를 상담합니다.'
- 구조: 공간 중심 풀스크린 히어로 → 진료 철학 → 1인 시술 공간 → 의료진 → 서비스 3갈래 → 방문 순서 → 위치/상담.
- A01 hero: 위 헤드라인, CTA '진료 상담 안내'.
- A02 philosophy: '먼저 듣고, 세심하게 살핍니다.' / '관심 부위와 피부 상태를 바탕으로 의료진과 진료 방향을 상담합니다.'
- A03 private: '나에게 집중하는 공간' / '독립된 1인 시술실을 안내합니다.' 실제 시설 사진 없을 때 생성 공간을 병원으로 오인시키지 말고 추상 소재로 대체.
- A04 people: '진료의 기준을 만드는 의료진' / '의료진 소개와 진료 분야를 확인하세요.' CTA '의료진 알아보기'.
- A05 care: '피부의 고민에 맞춰 살펴보세요.' 리프팅 / 콜라겐·스킨부스터 / 재생 프로그램. 상세 안내는 공식 원문 링크로 연결, 후자는 의료진 상담 필요 표시.
- A06 journey: '상담부터 방문까지' 문의 → 일정 안내 → 내원 상담. 예약 확정/완료로 오인시키지 않음.
- A07 visit: '청담에서 만나는 디오디' 주소·전화·공식 위치 링크. CTA '방문 안내 보기'.
- 리사 제안: 따뜻한 밝은 톤, 비대칭 넓은 여백, 느린 빛/소재 영상. 긴 랩 구간 없이 공간/본문 교차.
- 이미지 요청: 추상 빛·유리·직물의 시네마틱 영상. 가상 병원/가짜 의사 금지.

## B — PRECISION ATLAS / 이해하고 선택하는 진료
- 컨셉: 진단과 서비스 선택 기준을 읽고 비교하는 인터랙티브 메디컬 아틀라스.
- 타깃 가설: 장비/시술을 검색했지만 차이를 이해하고 싶은 탐색자.
- 메시지: '선택에 앞서, 피부를 이해하다' / '진단 과정과 진료 분야를 차근히 살펴보세요.'
- 구조: 대형 타이포+추상 3D 히어로 → 진단 과정 → 관심사 탐색 → 분야별 설명 → 의료진 → 질문 → 상담.
- B01 hero: 위 메시지, CTA '진료 분야 탐색'.
- B02 diagnosis: '진료의 출발점은 상태를 살피는 일' / '홈페이지에서 안내하는 MetaVu 진단 시스템과 상담 과정을 소개합니다.' 장비가 깊이/효능을 보장한다고 과장하지 않음.
- B03 explorer: '어떤 고민이 있으신가요?' 탄력·윤곽 / 피부결·건조 / 색소·흉터. 선택 시 관련 공식 진료 링크와 질문 안내를 표시. 자동 진단/개인별 시술 추천/민감정보 저장 없음.
- B04 atlas: '이름보다 중요한, 선택의 기준' 각 분야에서 개요·상담 시 확인할 점·개인차 안내. 다운타임/부작용 수치는 의료진 검토 전 쓰지 않음.
- B05 people: '판단은 의료진과 함께' 의료진 소개·상담 CTA.
- B06 faq: '상담 전에 궁금한 점' 시술 선택은 어떻게 하나요? / 위치와 진료시간은? / 상담과 예약 확정은 어떻게 다른가요? 사실 확인된 답변만 사용.
- B07 contact: '나에게 필요한 질문부터 시작하세요.' 공식 상담 채널 안내.
- 리사 제안: 차가운 밝은 톤/짙은 잉크, 모듈형 정보 그리드, 선/좌표/추상 입자의 정교한 three.js. 입자 모션은 과학적 효과 증거가 아닌 그래픽.
- 이미지 요청: 의료 결과를 재현하지 않는 추상 레이어/좌표 그래픽. 텍스트와 탐색 UI는 실제 DOM.

## C — THE DOD EDIT / 나의 관심사로 여는 에디토리얼
- 컨셉: 독자의 관심사를 출발점으로 의료진·프로그램·방문 안내를 큐레이션하는 하이패션 저널.
- 타깃 가설: 브랜드 취향과 다양한 선택지를 빠르게 둘러보려는 모바일 탐색자.
- 메시지: '오늘의 관심에서 시작하는 피부 이야기' / '디오디의 진료 분야와 공간, 사람을 새로운 순서로 만나보세요.'
- 구조: 타이포 에디토리얼 커버 → 관심 주제 인덱스 → 대표 분야 스토리 → 의료진 인터뷰형 소개 → 프로그램/프로모션 → 방문 정보.
- C01 cover: 위 메시지, CTA '관심 주제 둘러보기'.
- C02 contents: '지금, 궁금한 것은 무엇인가요?' 탄력 이야기 / 피부결 이야기 / 디오디의 공간. 선택은 진료 진단이 아니라 콘텐츠 이동.
- C03 features: '진료를 읽는 세 가지 시선' 리프팅·부스터·상담 과정을 잡지형 대형 기사 카드로 소개. A처럼 동일한 3카드 서비스 목록을 반복하지 않음.
- C04 people: '사람을 통해 알아보는 디오디' 실제 승인된 소개문만 사용. 가상의 의료진 발언/인터뷰 인용 금지.
- C05 programs: '프로그램 안내' 공식 현재 이벤트를 직접 확인하기 전 가격·기간·할인율을 만들지 않음. 미확인 시 '공식 프로그램 안내 확인' 링크만 제공.
- C06 visit: '다음 페이지는, 청담에서' 주소·전화·공식 방문 안내. CTA '상담 채널 보기'.
- 리사 제안: 대담한 잉크/포인트 컬러, 세리프·산세리프 대비, 잡지 콜라주, 경쾌한 타이포 마스크 전환. 가로 이동은 선택형 갤러리로 제한하고 본문 스크롤을 가로채지 않음.
- 이미지 요청: 추상 오브제/컬러 필름 스틸. 가짜 환자 후기·전후 사진 금지.

## 검색/SEO/GEO — 가설과 운영 기준
검색량 확인 전 후보 키워드: 브랜드형 '디오디피부과 청담', 지역형 '청담 피부과', 서비스형 '청담 리프팅', '청담 써마지', '청담 울쎄라', '청담 스킨부스터', 정보형 '리프팅 상담', 방문형 '디오디피부과 위치/진료시간'. 나열식 본문 삽입 대신 개별 실제 콘텐츠와 연결. 법규·의학 검토가 필요한 재생 관련 키워드를 유입 목적으로 과장하지 않음.
- 초안 3개와 선택 인덱스는 공개 데모라는 점을 명시하고 noindex. 실제 고객 홈페이지와 검색 경쟁/중복을 만들지 않음. 검색 최적화 구현과 색인 허용은 별개.
- 본 사이트 출시에만 의료진 승인 콘텐츠, 실제 주소·전화·운영시간, 검토일, 시맨틱 헤딩, canonical, sitemap, 필요한 다국어 hreflang을 적용.
- 데모 title: '디오디청담 | A 프라이빗 아틀리에 — 디자인 초안' 등으로 구분. 각 페이지 H1 1개, 섹션 H2, 세부 H3. 사실과 맞지 않는 서비스/리뷰 JSON-LD 금지. 고객 운영 사이트로 오인시키는 예약 상태/Review/AggregateRating 금지.
- FAQ는 화면에 실제로 읽을 수 있게. 구조화 데이터나 llms.txt만으로 AI 인용·검색 순위 상승을 보장하지 않음.
- 문의 폼은 데모에서 실제 개인정보를 수집하지 말고 공식 채널 링크와 데모 표시 사용. 생성 그래픽 alt는 장식/추상임을 반영.

## 검수 대응표
각 섹션은 A01~A07, B01~B07, C01~C06 번호를 고정해 anchor/캡처와 연결. 완성 시 빌드 버전·캡처 시각·PC1440/모바일390·360·HTML·메타 표를 같은 버전으로 전달.
차별화 통과 조건: 히어로 매체/섹션 순서/주 CTA/주요 탐색 경험/그리드/모션 리듬 중 적어도 4개가 다를 것. 공통된 주소·전화·의료 사실은 변형하지 않음.
현재 세 방향은 기획 제안이며 최종 고객 승인본 아님. 리사의 시각 명세와 니키타 검토 후 버전 갱신.
