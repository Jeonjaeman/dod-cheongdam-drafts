# 디오디피부과 청담 — 새 초안 3개 첫 2스크린 스토리보드

기존 저품질 초안은 폐기합니다. 아래는 레퍼런스 공동 평가 후 선정 제안이며, 타이포 px와 색은 모두 제안값입니다. 원본 사이트 측정값이 아닙니다. 브랜드는 병원이므로 기술 과시가 아닌 진료 신뢰가 기준입니다.

## 공통 기준(3안 동일 적용)
- 자산: 의료진·시설·효능을 합성하거나 실제처럼 연출 금지. 승인 자산 없을 때 추상 영상은 브랜드 장면으로만 쓰고 실제 진료 설명은 승인 콘텐츠 영역으로 분리.
- 구현: 전체 화면 WebGL도 장면 목적에 맞으면 사용. DOM 설명·문의는 접근 가능하게 유지. 소연의 Apple 계측 근거로 안1에서 영상 currentTime seek 스크럽을 기술 테스트한다. 이미지 시퀀스로 잘못 부르지 않으며 실제 디오디 영상의 적합성은 별도 검수한다. 자동재생 영상 / seek / 이미지 시퀀스를 설계서에 구분 표기.
- 검증: 이미지 선명도(2x, 압축 아티팩트 없음), 모바일에서 PC와 동일 서사 순서, 문의·진료 문의 버튼 상시 노출, reduced motion 시 정지 이미지로 대체, 키보드 포커스 순서 정상, 영상 로딩 실패 시 포스터 이미지와 텍스트만으로 메시지 전달.

## 안 1. 「진료가 머무는 공간」
- 고객 메시지: 한 사람의 피부 상태를 살피는 상담과 프라이빗 진료 경험. (기획 검토용 메시지)
- 출처: Lanserhof(경험 영상+진료 문의 버튼), Locomotive(강한 영상→읽는 편집면), 봄결(인물 프레임→전면 확장, 한국어 2행), 더가든(실제 공간·의료진 영상+로고 연결선).
- 주 인터랙션: 스크롤로 프레임이 전면 확장되는 영상 전환.

|---|---|

- 고객 메시지: 피부를 마주하는 여러 시선. 지속 관리 체계에 대한 미확인 주장은 하지 않음.

## v1.2 실제 자산·모바일 기준
니키타가 수집한 공식 사이트 자산 시트를 리사가 직접 확인했다. 라운지·복도·진료실·의료진 프로필·장비/연구 이미지가 있으므로 실자산 후보가 없다는 전제는 폐기한다. 다만 다운로드/공개 게시와 재사용·영상 변형 허락은 구분한다. 의료진 이름·현재 소속·사진을 대조하기 전 전원을 현재 재직자로 확정하지 않는다. 지정서 이미지의 존재와 공적 독립 대조도 구분한다.
공식 사진은 내부 레이아웃/크롭 후보로 검토하며 공개 재사용 범위는 대표님에게 확인한다. 이미지→영상에서 보이지 않는 문 너머·시술실로 들어가는 동선 생성은 보류한다. 승인 후에도 원본 프레임 안에서의 미세한 빛/제한된 시점 이동을 우선 검토하며 실제 촬영 영상이라 표시하지 않는다.
모바일 공통: 전화·카카오 하단 문의 바 + safe-area, 핵심 이미지/카피 가림 금지. svh와 주소창 리사이즈 대응은 실제 iOS 검증. C 콜라주는 한 시점에 4장 이내, 이미지 최소 폭 120px·캡션 13px 이상 단색 면. 6개 콘텐츠는 순차 등장으로 모두 제공.
